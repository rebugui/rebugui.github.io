# W-08 계정 잠금 기간 설정

| **점검대상** | Windows NT, 2000, 2003, 2008, 2012, 2016, 2019, 2022 |
| **양호기준** | '계정잠금기간'및'계정잠금기간원래대로설정기간'이60분이상으로설정된경우 |
| **취약기준** | '계정잠금기간'및'잠금기간원래대로설정기간'이설정되지않거나60분미만으로설정된경우 |

## 상세 설명

### 1. 판단 기준

#### 기본 판단 기준
- **양호**: '계정 잠금 기간' 및 '계정 잠금 수를 원래대로 설정하기 위한 시간'이 60분 이상으로 설정된 경우
- **취약**: '계정 잠금 기간' 및 '잠금 기간 원래대로 설정 기간'이 설정되지 않거나 60분 미만으로 설정된 경우

#### 경계 케이스 (Edge Case) 처리 방법

| 상황 | 판단 기준 | 설명 |
|------|----------|------|
| 계정 잠금 기간 0(무제한) | 주의 | 영구 잠금. DOS 공격 악용 가능성 있음. 권장하지 않음 |
| 계정 잠금 기간 30분 | 주의 | 보안과 편의성 균형. 공격 빈도 높은 환경에서는 부족 |
| Administrator 계정 | 양호 | Administrator 계정은 잠금에서 제외 권장 |
| 도메인 컨트롤러 | 주의 | 도메인 환경에서는 GPO로 일괄 적용 필요 |

#### 권장 설정값

| 환경 | 항목 | 권장 설정 | 비고 |
|------|------------|---------------|------|
| 일반 서버 | 계정 잠금 기간 | 60분 | 공격 효율 감소 |
| 보안 강화 서버 | 계정 잠금 기간 | 30분 | 공격 빈도 높은 환경 |
| DMZ 서버 | 계정 잠금 기간 | 30분 | 외부 노출 서버 |
| 모든 환경 | 잠금 관찰 시간 | 15분 | 실패 횟수 리셋 주기 |
| 모든 환경 | 계정 잠금 임계값 | 5회 (W-04) | 계정 잠금 트리거 |

### 2. 점검 방법

#### Windows 서버 점검

계정 잠금 기간은 비밀번호 추측 공격을 방지하기 위한 중요한 보안 설정입니다. 너무 짧으면 공격자가 계속 공격할 수 있고, 너무 길면 DOS 공격에 악용될 수 있습니다.

```bash
# PowerShell - 계정 잠금 정책 확인
net accounts

# 또는
secedit /export /cfg config.inf
Get-Content config.inf | Select-String "Lockout"
```

**양호 출력 예시:**
```text
잠금 기간(분): 60
잠금 관찰 시간(분): 15
잠금 임계값: 5
```
잠금 기간이 60분 이상인 경우 양호

**취약 출력 예시:**
```text
잠금 기간(분): 30
잠금 관찰 시간(분): 10
잠금 임계값: 5
또는
잠금 기간(분): 0
```
잠금 기간이 60분 미만이거나 0(무제한)인 경우 취약

### 3. 조치 방법

#### Windows 서버 설정

1. **명령 프롬프트 설정**
   ```cmd
   net accounts /lockoutduration:60
   net accounts /lockoutwindow:60
   ```

2. **PowerShell 설정**
   ```powershell
   # 계정 잠금 기간 60분 설정
   net accounts /lockoutduration:60 /lockoutwindow:60

   # 설정 확인
   net accounts
   ```

3. **로컬 보안 정책 설정 (GUI)**
   ```
   시작 > 제어판 > 관리 도구 > 로컬 보안 정책
   계정 정책 > 계정 잠금 정책
   "계정 잠금 기간" 더블클릭
   값으로 60 이상 입력 (권장: 60)
   "계정 잠금 수를 원래대로 설정하기 위한 시간" 더블클릭
   값으로 60 이상 입력 (권장: 60)
   확인 클릭
   ```

4. **그룹 정책(GPO) 설정 (도메인 환경)**
   ```
   GPO 편집기(gpedit.msc 또는 gpmc.msc)
   컴퓨터 구성 > 정책 > Windows 설정 > 보안 설정 > 계정 정책 > 계정 잠금 정책
   "계정 잠금 기간" 설정: 60분 이상
   "계정 잠금 수를 원래대로 설정하기 위한 시간" 설정: 60분 이상
   ```

5. **계정 잠금 이벤트 모니터링**
   ```powershell
   # 최근 계정 잠금 이벤트 확인 (이벤트 ID 4740)
   Get-WinEvent -FilterHashtable @{
       LogName='Security';
       ID=4740;
       StartTime=(Get-Date).AddDays(-7)
   } -MaxEvents 20 | Format-List
   ```
