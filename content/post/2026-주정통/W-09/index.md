# W-09 비밀번호 관리 정책 설정

## 가이드라인 원문

| 항목 | 내용 |
|------|------|
| **항목코드** | W-09 |
| **점검내용** | 계정비밀번호관리정책설정여부점검 |
| **점검대상** | Windows NT, 2000, 2003, 2008, 2012, 2016, 2019, 2022 |
| **양호기준** | 계정비밀번호관리정책이모두적용된경우 |
| **취약기준** | 계정비밀번호관리정책이모두적용되어있지않은경우 |
| **조치방법** | 비밀번호복잡성,최소비밀번호길이,최대/최소사용기간을기준에맞게설정 |

## 상세 설명

### 1. 판단 기준

#### 기본 판단 기준
- **양호**: 다음 모든 조건을 만족하는 경우
  - 암호는 복잡성을 만족해야 함: 사용
  - 최근 암호 기억: 4개 이상
  - 최대 암호 사용 기간: 90일 이하
  - 최소 암호 길이: 8 문자 이상
  - 최소 암호 사용 기간: 1일 이상
- **취약**: 위 조건 중 하나라도 만족하지 않는 경우

#### 경계 케이스 (Edge Case) 처리 방법

| 상황 | 판단 기준 | 설명 |
|------|----------|------|
| 최대 사용 기간 0일 | 취약 | 비밀번호 만료 없음. 보안 취약 |
| 최소 사용 기간 0일 | 주의 | 즉시 변경 가능. 비밀번호 순환 공격 가능성 |
| 최소 길이 7자 이하 | 취약 | 크래킹 용이 |
| 복잡성 요구사항 비활성화 | 취약 | 단순 비밀번호 사용 가능 |
| 서비스 계정 | 주의 | 비밀번호 변경 시 서비스 재시작 필요 |

#### 권장 설정값

| 환경 | 항목 | 권장 설정 | 비고 |
|------|------------|---------------|------|
| 모든 서버 | 암호 복잡성 요구 | 사용 | 영문 대소문자+숫자+특수문자 |
| 모든 서버 | 최소 암호 길이 | 8~14 문자 | 권장 12자 이상 |
| 모든 서버 | 최대 사용 기간 | 90일 | 권장 60~90일 |
| 모든 서버 | 최소 사용 기간 | 1일 | 빈번한 변경 방지 |
| 모든 서버 | 기억 암호 수 | 4~24개 | 권장 4개 이상 |

### 2. 점검 방법

#### Windows 서버 점검

비밀번호 관리 정책은 시스템 보안의 기본이 되는 중요한 설정입니다. 강력한 비밀번호를 강제하여 크래킹 공격을 방지해야 합니다.

```bash
# PowerShell - 비밀번호 정책 확인
net accounts

# 또는 secedit로 확인
secedit /export /cfg password_policy.inf
Get-Content password_policy.inf | Select-String "Password"
```

**양호 출력 예시:**
```text
암호의 최소 사용 기간: 1일
암호의 최대 사용 기간: 90일
암호의 최소 길이: 8 문자
암호 길이 기록 유지: 0
암호 기억: 4
```
모든 항목이 권장값을 만족하면 양호

**취약 출력 예시:**
```text
암호의 최소 사용 기간: 0일
암호의 최대 사용 기간: 42일
암호의 최소 길이: 0 문자
암호 기억: 0
```
하나 이상의 항목이 권장값 미달이면 취약

### 3. 조치 방법

#### Windows 서버 설정

1. **명령 프롬프트 설정**
   ```cmd
   net accounts /maxpwage:90 /minpwage:1 /minpwlen:8
   ```

2. **PowerShell 설정**
   ```powershell
   # 비밀번호 정책 설정
   net accounts /maxpwage:90 /minpwage:1 /minpwlen:8

   # 설정 확인
   net accounts
   ```

3. **로컬 보안 정책 설정 (GUI)**
   ```
   시작 > 제어판 > 관리 도구 > 로컬 보안 정책
   계정 정책 > 암호 정책
   다음 각 항목 설정:
   - 암호는 복잡성을 만족해야 함: 사용
   - 최근 암호 기억: 4개
   - 최대 암호 사용 기간: 90일
   - 최소 암호 길이: 8 문자
   - 최소 암호 사용 기간: 1일
   ```

4. **그룹 정책(GPO) 설정 (도메인 환경)**
   ```
   GPO 편집기(gpedit.msc 또는 gpmc.msc)
   컴퓨터 구성 > 정책 > Windows 설정 > 보안 설정 > 계정 정책 > 암호 정책
   위 항목들을 동일하게 설정
   ```

5. **서비스 재시작**
   ```powershell
   # 서비스 계정 비밀번호 변경 시
   Stop-Service -Name "서비스명"
   # 비밀번호 변경
   $NewPassword = ConvertTo-SecureString "새비밀번호" -AsPlainText -Force
   Set-ADAccountPassword -Identity "서비스계정" -NewPassword $NewPassword
   # 서비스 등록 정보 업데이트
   Start-Service -Name "서비스명"
   ```
