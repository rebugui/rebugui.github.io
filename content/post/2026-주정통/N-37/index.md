# N-37: pad 차단

## 가이드라인 원문

| 항목 | 내용 |
|------|------|
| **항목코드** | N-37 |
| **점검내용** | PAD서비스를차단하는지점검 |
| **점검대상** | Cisco등 |
| **판단기준** | 양호: PAD서비스를차단하는경우 |
| **판단기준** | 취약: PAD서비스를차단하지않은경우 |
| **조치방법** | PAD서비스비활성화 |

---
## 상세 설명

### 개요

pad 차단 항목은 X.25 프로토콜을 사용하지 않는 경우 PAD(Packet Assembler/Disassembler) 서비스를 중지하는 항목입니다.

### 필요성

**보안 위협**

PAD와 같이 불필요한 서비스를 차단하지 않을 경우 잠재적인 취약점 및 공격에 노출될 수 있습니다.

**PAD란?**

X.25 패킷 교환망에 패킷 처리 기능이 없는 비동기형 단말기의 연결을 제공하는 서비스로, 비동기형 단말기로부터 수신한 문자 스트림을 X.25 패킷으로 분해하고 반대로 X.25 패킷을 문자 스트림으로 재조합하여 상호 전송합니다.

### 점검 및 조치 방법

#### Cisco IOS

**점검**: `no service pad` 설정 확인

```
Router# show running-config
```

**조치**: Global Configuration 모드에서 비활성화

```
Router# config terminal
Router(config)# no service pad
```

**권장 설정**:
- X.25를 사용하지 않는 경우 PAD 서비스 비활성화
