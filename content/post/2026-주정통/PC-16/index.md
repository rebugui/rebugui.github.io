# 화면보호기 대기 시간 설정 및 재시작 시 암호 보호 설정

## 가이드라인 원문

| 항목 | 내용 |
|------|------|
| **항목코드** | PC-16 |
| **점검내용** | 화면보호기대기시간및화면보호기재시작시비밀번호설정여부점검 |
| **점검대상** | Windows 10, Windows 11 |
| **양호기준** | 화면보호기설정(대기시간10분이하)및비밀번호로보호가설정된경우 |
| **취약기준** | 화면보호기설정(대기시간10분초과)및비밀번호로보호가설정되지않은경우 |
| **조치방법** | 화면보호기설정및비밀번호보호설정 |

## 상세 설명

### 1. 판단 기준

#### 기본 판단 기준
- **양호**: 화면보호기 설정(대기시간 10분 이하) 및 비밀번호로 보호가 설정된 경우
- **취약**: 화면보호기 설정(대기시간 10분 초과) 및 비밀번호로 보호가 설정되지 않은 경우

#### 경계 케이스 (Edge Case) 처리 방법
- **화면보호기가 (없음)인 경우**: 비밀번호 보호 불가, 취약 판단
- **대기 시간이 10분 초과**: 취약 판단
- **비밀번호 보호 체크 해제**: 취약 판단

#### 권장 설정값
- **화면보호기**: (없음) 이외의 항목
- **대기 시간**: 10분 이하
- **재시작 시 로그온 화면으로 돌아가기**: 체크

### 2. 점검 방법

#### Windows 10, 11에서의 점검

```
Step 1) 시작 > 설정 > 개인 설정
Step 2) 잠금화면 > 화면보호기 설정
```

### 3. 조치 방법

#### 1. 화면보호기 설정

```
Step 1) 바탕화면 우클릭 > 개인 설정
Step 2) 잠금화면 > 화면보호기 설정
Step 3) 화면보호기: (없음) 이외의 항목 선택
Step 4) 대기 시간: 10분 이하로 설정
Step 5) '재시작 시 로그온 화면으로 돌아가기' 체크
Step 6) 적용 > 확인
```

### 4. 참고 자료

#### 화면보호기와 암호 보호의 중요성

**보안 위협:**
- **물리적 접근 방지**: 사용자가 자리를 비운 사이 비인가 접근 방지
- **정보 유출 방지**: 열려 있는 문서, 이메일 등 보호
- **책임 소재 명확화**: 사용자별 계정 보안 유지
