## 상세 설명

### 1. 항목 개요

운영체제, 응용프로그램, 펌웨어 등에 대해 안정성이 확인된 최신 버전의 소프트웨어를 사용하고 기술지원이 종료된 제품을 미사용하는 것은 제어시스템의 안정적인 운영을 위한 필수적인 보안 활동입니다.

기술지원이 종료된 소프트웨어는 새로운 취약점이 발견되어도 조치가 불가능하며, 이로 인해 지속적인 보안 위협에 노출됩니다.

### 2. 왜 이 항목이 필요한가요?

이 항목은 제어시스템에서 사용하는 운영체제, 응용프로그램, 펌웨어 등이 기술지원이 종료되지 않은 최신 버전으로 운용하도록 하여 안정적인 제어시스템 운영이 가능하도록 하기 위함입니다.

**보안 위협 시나리오:**
1. **기술지원 종료 제품의 취약점**
   - 기술지원이 종료된 S/W에 취약점 발견 시 조치 불가능
   - 해당 취약점의 지속적 노출
   - 악성코드 감염 및 침해 사고 발생

2. **Microsoft Windows 7 지원 종료 사례**
   - '20. 1. 24. 이후 Microsoft Windows 지원 종료
   - 업데이트, 문제 관련 기술지원, 보안업데이트 미수행
   - 지속적인 보안 위협 노출

3. **보안 업데이트 중단**
   - 새로운 취약점에 대한 패치 제공 안 함
   - 알려진 취약점 악용 가능성 증가

### 3. 점검 대상

- 제어시스템 구성요소 전체
- 운영체제
- 응용프로그램
- 펌웨어

### 4. 판단 기준

- **양호**: 제어시스템 구성요소가 사용하는 운영체제, 응용프로그램, 펌웨어 등이 기술지원이 종료되지 않은 최신 제품을 사용하는 경우
- **취약**: 제어시스템 구성요소가 사용하는 운영체제, 응용프로그램, 펌웨어 등이 기술지원이 종료되었거나, 최신 버전이 아닌 경우

### 5. 점검 방법

#### 공통 점검 절차

**Step 1) 최신 버전 사용 여부 확인**

제어시스템 구성요소 현황을 통해 제어 H/W, 정보시스템, 네트워크 장비에서 사용하는 운영체제, 펌웨어가 제조사에서 제공하는 최신 버전이 맞는지 확인하고, 제어 S/W가 제조사에서 제공하는 최신 버전이 맞는지 확인합니다.

- 제조사에서 제공하는 최신 버전이 아닌 경우, 이에 대한 사유(제조사 공식 의견)가 안정성 확보이며, 해당 버전이 취약점이 없는 경우 양호한 것으로 판단 가능

**Step 2) 기술지원 종료 여부 확인**

Step 1)에서 확인한 버전이 제조사에 확인하여 기술지원 종료 예정이 없는지 확인합니다.

- 제어시스템에서 사용하는 운영체제, 펌웨어, 응용프로그램 등이 기술지원 종료 예정일 경우, 이에 대한 대응방안(업데이트 일정 수립, 별도 기술지원 계약 등) 수립을 권고

### 6. 조치 방법

#### 최신 버전 업데이트

1. **운영체제 업데이트**
   - 최신 버전으로 업그레이드
   - 기술지원이 종료되지 않은 버전 사용

2. **응용프로그램 업데이트**
   - 최신 버전으로 업그레이드
   - 제조사 제공 보안패치 적용

3. **펌웨어 업데이트**
   - 최신 펌웨어로 업그레이드
   - 기술지원이 종료되지 않은 버전 사용

#### 기술지원 종료 대응

1. **업데이트 일정 수립**
   - 기술지원 종료 예정 제품에 대한 업데이트 계획 수립
   - 충분한 시간을 두고 단계적 업그레이드

2. **별도 기술지원 계약**
   - 불가피하게 기술지원 종료 제품을 사용해야 하는 경우
   - 제조사와 별도 기술지원 계약 체결

3. **완화 대책 수립**
   - 업데이트가 어려운 경우 보안 완화 대책 수립
   - 네트워크 접근통제 강화
   - 모니터링 강화

### 7. 조치 시 주의사항

- 일반적인 경우 영향 없음
- 업데이트 전 반드시 테스트 환경에서 검증
- 운영 중인 시스템에 영향이 없도록 철저한 사전 준비
- 제어시스템 특성상 업데이트가 어려운 경우 보완대책 필수
